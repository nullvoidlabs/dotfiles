# 43PR/dotfiles — Fedora package map
#
# One package per line. "a|b" means: install the first name that exists in
# your enabled repos (Fedora + the COPRs fedora/install.sh enables).
# Anything not resolvable is reported at the end, never fatal.
#
# Arch name (upstream packages.txt)      -> Fedora name
#
# Not installed via dnf (handled in fedora/install.sh instead):
#   matugen, starship, eza, cliphist   -> cargo/go build into /usr/local/bin if dnf has no package
#   ttf-jetbrains-mono-nerd, ttf-iosevka-nerd -> Nerd Fonts release tarballs into ~/.local/share/fonts
#   papirus-folders                     -> upstream script from GitHub
#   gpu-screen-recorder                 -> Flathub (official), wrapped by hypr/scripts/gsr-toggle.sh
#   hyprmod                             -> optional, pipx (only with --with-hyprmod)
#   power-profiles-daemon               -> only if tuned-ppd isn't already managing power profiles
#
# Renamed or folded in (keeps fedora/update.sh's "unmapped upstream package" check quiet):
#   qt6-wayland -> qt6-qtwayland, xorg-xwayland -> xorg-x11-server-Xwayland,
#   pipewire-audio -> pipewire, ttf-roboto-mono -> google-roboto-mono-fonts,
#   otf-font-awesome -> fontawesome-6-free-fonts
